# ساعت بازی 🕐

اپلیکیشن آموزشی اندروید برای آموزش خواندن ساعت عقربه‌ای به کودکان ۶ تا ۹ ساله فارسی‌زبان.

## تغییرات نسخهٔ جدید
- ✅ **همهٔ مراحل باز هستند** — کودک می‌تواند هر دنیا و مرحله را انتخاب کند
- ✅ **پاسخ درست → اتوماتیک بعدی** — بعد از ۲ ثانیه به پرسش بعدی می‌رود
- ✅ **پاسخ غلط → پیام تلاش دوباره** — کودک می‌تواند دوباره امتحان کند
- ✅ **گرافیک فانتزی** — گرادیان چندرنگ، سایه‌های ۳بعدی، رنگ‌های جادویی
- ✅ **نام «ساعت بازی»** — نام فارسی جذاب
- ✅ **آیکون جدید** — ساعت فانتزی با ستاره‌ها
- ✅ **انیمیشن انتقال** — حرکت نرم بین صفحات با scale + slide + fade

## ساخت APK با GitHub Actions
۱. مخزن GitHub بساز
۲. فایل‌ها را push کن
۳. ۴ Secret اضافه کن: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD
۴. Actions → Run workflow → APK از Artifacts دانلود کن

## ساخت محلی
```sh
flutter pub get
flutter run
flutter build apk --release
```
